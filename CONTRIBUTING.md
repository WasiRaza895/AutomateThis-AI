# Contributing

Thanks for improving No-Code Automation Commander.

Good contributions include:

- New workflow patterns
- Better no-code recipes
- Better risk controls
- Export formats for n8n, Zapier, or Make
- Accessibility and responsive design fixes
- Clear examples for specific business roles

## Local Development

Open `index.html` in your browser and edit the static files:

- `index.html`
- `styles.css`
- `app.js`

No package manager is required.

## Pull Request Checklist

- The app still opens without a build step.
- New copy is clear and practical.
- Automation recommendations include human approval or safety controls where needed.
- Mobile layout still works.
